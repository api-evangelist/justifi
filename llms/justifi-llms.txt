# JustiFi

> JustiFi is an embedded-payments / PayFac-as-a-service platform for SaaS companies. Its REST API (base https://api.justifi.ai/v1) and StencilJS web components let platforms onboard sub-merchants, tokenize cards and bank accounts, process payments, manage payouts, proceeds, disputes, checkouts, and card-present terminals — with PCI-DSS Level 1 and SOC 2 compliance handled by JustiFi.

## APIs
- [JustiFi API (v1)](https://docs.justifi.tech/api-spec): 90 operations across payments, payment methods, refunds, disputes, payouts, sub accounts, checkouts, terminals, reporting. OAuth 2.0 client-credentials -> Bearer.
